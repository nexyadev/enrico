# Enrico Rocha Miascovsky — Portfólio

Portfólio editorial de Marketing & Content Strategy, com cinco cases, galeria de fotografias, vídeo do manifesto GiG House e narrativa espacial em WebGL.

## Tecnologia

HTML, CSS e JavaScript. Three.js r169, GSAP 3.13.0 e ScrollTrigger 3.13.0 estão incorporados ao único `script.js`; `styles.css` é a única folha de estilo. O projeto não requer backend nem etapa de build para execução. O aviso de licença do Three.js está em `assets/vendor/THREE-LICENSE.txt`.

## Visualização

Abra `index.html` diretamente ou sirva a pasta por HTTP para testar no navegador. Em `file://`, `script.js` carrega `assets/enrico/file-media-data.js`, que contém cópias das texturas e do vídeo necessárias à reprodução WebGL local. Por HTTP, esse arquivo auxiliar não é carregado: imagens e vídeo usam diretamente os arquivos otimizados em `assets/enrico/`.

## Publicação

Publique `index.html`, `styles.css`, `script.js` e `assets/` na mesma estrutura. Os caminhos relativos também funcionam em subpastas como `/enrico/`. Configure a URL pública de compartilhamento social quando o domínio final estiver definido.

Os links externos dos cases levam às fontes originais. O case Banco Inter apresenta apenas texto aprovado para divulgação pública. O player YouTube depende da disponibilidade da plataforma. Nenhum dado de contato foi fornecido para publicação.
